# Установка, управление, проблемы

## Запуск
1. godotengine.org → скачать Godot 4.7.2 Standard (обычный, не .NET). Установка не нужна.
2. Распаковать архив в простую папку, например `C:/Games/rift_game`.
3. Godot → Import → `project.godot` → Import & Edit.
4. F5 — запуск. Ошибки появляются внизу: вкладки Debugger → Errors и Output.

RPG поддерживает экранные сенсорные кнопки на Android. RTS пока рассчитан на мышь и клавиатуру; сенсорное выделение отрядов и приказы ещё не реализованы.

## Управление RPG
| Действие | Клавиши |
|---|---|
| Движение | WASD / стрелки |
| Атака (комбо) | ЛКМ / J |
| Уворот | Пробел / ПКМ |
| Навыки | Q, E, R |
| Зелье | 1 / H |
| Взаимодействие, диалоги | F (диалоги также клик и Enter) |
| Пауза | Esc |
| Отладка: пропустить этап RPG | F10 (вне диалога) |

## Сенсорное управление RPG на Android
На экране доступны крестовина движения, взаимодействие, атака, уворот, Q/E/R и зелье. Раскладка рассчитана на горизонтальную ориентацию 1280×720 и требует проверки на реальном устройстве.

## Управление RTS
| Действие | Клавиши |
|---|---|
| Выделить / рамка | ЛКМ (Shift — добавить юнитов) |
| Идти / атаковать / добывать / достроить | ПКМ |
| Точка сбора здания | выделить здание, ПКМ по земле |
| Атака по пути | A, затем ЛКМ |
| Стоп | S |
| Казарма / башня / палатка (выделен рабочий) | B / T / H |
| Волна героини | Q |
| Камера | стрелки, край экрана, миникарта, колесо |
| К героине | Пробел |
| Сохранить / выбрать отряд | Ctrl+1..3 / 1..3 |

Первая стратегия: найми 1–2 рабочих → построй казарму → найми 3–4 бойцов до первой волны →
поставь палатку → поставь башню → собери 10+ бойцов и атакуй обелиски по очереди.

## Сохранения
Автосохранение при переходе между этапами (`user://save.json`). «Новая игра» перезаписывает его.

## Частые проблемы
- **Красная ошибка при запуске.** Скопируй её целиком (файл и номер строки) и отправь в ChatGPT по шаблону из 04.
- **Спрайты стали мутными.** Выдели PNG в FileSystem → вкладка Import → Compress Mode: Lossless,
  Mipmaps: выкл, Detect 3D → Compress To: Disabled → Reimport.
- **Godot предлагает обновить проект.** Это нормально для более новой версии. Сначала сделай копию папки.
- **«Нет файла res://...».** Нарушена структура папок: сравни с 03_files.md.
  `project.godot` должен лежать в корне. Регистр букв в именах важен.
- **Parse error про отступы.** В GDScript нельзя смешивать табы и пробелы. Здесь везде табы.

## Сборка .exe
1. Editor → Manage Export Templates → скачать шаблоны.
2. Project → Export → Add → Windows Desktop.
3. Вкладка Resources → «Filters to export non-resource files»: `*.json` — ОБЯЗАТЕЛЬНО,
   иначе в готовой игре не будет уровней и диалогов.
4. Перед релизом удали ветку F10 в `scripts/core/main.gd`.
5. Export Project.
