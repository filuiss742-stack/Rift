# Арт-ассеты — первый перенос

## Исходные SVG
- `assets/textures/wood_floor.svg` — текстура деревянного пола.
- `assets/textures/wallpaper.svg` — узор обоев.
- `assets/textures/rug.svg` — ковёр.
- `assets/textures/stone_ruins.svg` — каменная кладка руин.
- `assets/textures/ashen_ground.svg` — пепельная потрескавшаяся земля.
- `assets/sprites/lisa_idle_front.svg` — Лиза, вид спереди.
- `assets/sprites/lisa_idle_back.svg` — Лиза, вид сзади.
- `assets/sprites/lisa_idle_side.svg` — Лиза, вид сбоку; противоположная сторона зеркалится движком.

## Правила конвейера
1. Одна поза и одно направление на исходное изображение.
2. Проверять каждый кадр до сборки атласа.
3. Не генерировать сразу много поз в одном изображении: это ранее давало лишние конечности и артефакты.
4. Сохранять редактируемые исходники; PNG/атласы создавать после проверки.
5. Текущие SVG — временный первый проход, не финальные игровые ассеты.

## Ограничения
- У Лизы пока три статичных ракурса, не восемь направлений.
- В основном игровом прототипе направленные SVG применяются только на земном этапе; для Миры и врагов остаются PNG-атласы Клода.
- Текстуры пола подключены к земле этапов; стены и здания всё ещё используют преимущественно материалы-примитивы.
